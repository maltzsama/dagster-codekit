   - HTTP API:  port {{ .Values.service.httpPort }}
   - gRPC Proxy: port {{ .Values.service.grpcPort }}

2. Point your Dagster workspace at the gRPC proxy:
   ```yaml
   load_from:
     - grpc_server:
         host: {{ include "dagster-codekit.fullname" . }}
         port: {{ .Values.service.grpcPort }}
         location_name: your-location
   ```

3. Deploy a code location from CI/CD:
   ```bash
   dagster-codekit snapshot \
     --location your-location \
     --file definitions.py \
     --image registry.example.com/your-image:v1
   ```
